## Showing product data on labels

This guide explains how to insert product fields such as title, price, SKU, variant options, and metafields, and how to preview with a real variant.

### Insert a product field

1. Select a text, barcode, QR code, or image object that supports data.
2. Open the field / attribute controls in the sidebar (often labeled **Attribute** or similar).
3. Choose a field such as title, price, SKU, barcode, or a metafield.
4. Apply the selection so the canvas shows a token or resolved preview.

![screenshot:Attribute picker open while editing a text field](DynamicProductDataInsert.png)

### Preview with a real variant

Use the editor’s variant selector (when shown) to preview how the label looks for different products. This helps catch empty fields, long titles, and barcode issues before you print.

![screenshot:Editor preview switched to a specific product variant](DynamicProductDataVariantPreview.png)

### Common fields

Typical fields merchants use:

- Product or variant **title**
- **Price**
- **SKU**
- **Barcode**
- Variant **options** (size, color, and so on)
- **Metafields** your shop already stores on products or variants

Exact field lists depend on your store’s data and the object type you are editing.

### Empty values

If a field has no value for a product, that part of the label can print blank. That is normal when the data is missing. Fix the product in Shopify, or adjust the design so optional fields are not required for scanning or compliance.
